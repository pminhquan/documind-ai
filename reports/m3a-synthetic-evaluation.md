# M3A Synthetic Evaluation — Ruled Table Recognition

**Date:** 2026-10-25 · **Environment:** Windows, Python 3.12.10,
paddleocr 3.7.0 / paddlepaddle 3.3.1 (CPU, PP-OCRv6 medium det+rec),
opencv-contrib-python 4.10.0.84.

## Method

The full `documind-table` pipeline (real PaddleOCR inference) runs on
three synthetic ruled-table images generated by
`scripts/make_sample_tables.py` with committed ground truth in
`tests/fixtures/tables/*.truth.json`:

| Sample | Shape | Content focus |
|---|---|---|
| `table_products` | 4×4 | headers + numeric columns |
| `table_gaps` | 4×4 | empty cells + multi-word values |
| `table_large` | 6×5 | larger grid (30 cells) |

Metrics:

- **Structural correctness** — detected (rows, columns) equal ground truth.
- **Exact cell-text agreement** — per-cell string equality after
  whitespace collapse + casefold, **empty cells included**.

Reproduce with: `python scripts/evaluate_tables.py`.

## Results (actual run, 2026-10-25)

| Sample | Structure | Detected shape | Cells matched | Exact rate |
|---|---|---|---|---|
| table_products | ✓ | 4×4 | 16/16 | **1.00** |
| table_gaps | ✓ | 4×4 | 16/16 (empty cells preserved) | **1.00** |
| table_large | ✓ | 6×5 | 30/30 | **1.00** |
| **Overall** | 3/3 | — | **62/62** | **1.00** |

No mismatch details, no unassigned-region warnings on any sample.

Export verification on `table_products`: CSV content matches the ground
truth rows exactly, and the XLSX workbook (`table_0` sheet) reads back
identical values via openpyxl.

## Interpretation constraints

- These are **clean, rendered, axis-aligned** inputs — ideal conditions
  by construction. The 1.00 rates demonstrate the *pipeline works
  end-to-end and is deterministic on its target input class*; they are
  **not** real-world accuracy. Real photographs bring skew, noise,
  broken rules, and varied fonts that this baseline does not handle
  (see `docs/table-recognition-spec.md` limitations).
- No confidence calibration or per-field accuracy is claimed.
- A labeled evaluation set with real documents remains future work (M4).
